# Eurolotto Picker

A tiny, dependency-free web page that generates a random number set for Euromillions tickets.

## Rules

- 5 unique main numbers between 1 and 50 (inclusive), shown in ascending order.
- 2 unique "star" numbers between 1 and 12 (inclusive), shown alongside the main numbers.
- A button regenerates a fresh set without reloading the page.

## Running it

No build step or dependencies — just open [index.html](index.html) in a browser.

## Files

- `index.html` — page markup
- `style.css` — responsive styling
- `script.js` — number generation and rendering logic
